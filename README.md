# Lab3RZSI
## Постановка задачи
Ознакомиться с механизмом инъекции на примере пользовательского проекта и реализовать защиту от инъекции.
## Реализация
### Интеграция
Для имитации компьютера "жертвы" была использована виртуальная машина с опирационной системой Windows 10, туда была добавлена общая папка для передачи всех необходимых файлов в формате dll и exe (расположены в папке exe).\
Суть работы заключается в том, что при запуске TargetProcess.exe на машине жертвы и дальнейшем открытии Prize.exe появляется интерактивное окошко с активной кнопкой \
![image](https://github.com/user-attachments/assets/a2926589-3602-4c78-b3f3-ceb992775f7d)

при нажатии на которую выполняется инъекция вредоносной программы в целевой процесс. При успешной инъекции появляется следующее окошко\
![image](https://github.com/user-attachments/assets/fa79ae66-007f-430f-a38c-11b67a061065)\
Иньекция программы может осуществиться только при интеграции в запущенный процесс, если же процесс не запущен, то нажатие на кнопку не даст никакого результата.
### Защита
При запуске TargetProcess.exe на машине жертвы и дальнейшем открытии SecuritySecret.exe появляется точно такое же окошко с активной кнопкой, но при нажатии на кнопку вместо интеграции появляется сообщение об ошибке интеграции: \
